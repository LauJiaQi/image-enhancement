# Image Enhancement (Low-Light & Hazy Images)

## Overview

This project focuses on enhancing low-light and hazy images using image processing techniques.

The goal is to improve image visibility, contrast, and clarity.

---

## Techniques Used

* Gamma correction (brightness adjustment)
* LAB color space enhancement
* Histogram stretching (contrast improvement)
* Gaussian blur & sharpening
* Saturation adjustment (HSV)

---

## Approach

The enhancement pipeline includes:

1. Brightness correction using gamma transformation
2. Contrast enhancement in LAB color space
3. Noise reduction and sharpening
4. Color enhancement using HSV

---

## How to Run

1. Open the notebook:

```bash
jupyter notebook enhancement.ipynb
```

2. Run all cells to see the results

---

## Output

The enhanced image shows:

* Improved brightness
* Better contrast
* Clearer details
